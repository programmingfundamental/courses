# Лабораторно упражнение 1

## Входно-изходни операции. Обработка на файлове и колекции

### Задача 1

Да се разработи програма за обработка на лог файл на система.

Всеки ред от файла има формат:

```
timestamp;user;action
```

Например:

```
2026-03-15T10:15:20;ivan;LOGIN
2026-03-15T10:17:03;ivan;VIEW
2026-03-15T10:18:45;maria;LOGIN
2026-03-15T10:25:12;ivan;LOGOUT
```

Програмата трябва да:

- определи броя действия за всеки потребител;
- определи потребителя с най-много действия;
- изведе всички различни видове действия;
- изведе потребителите, които имат поне едно вписване в системата, но нямат изход от нея;
- запише резултатите в изходен файл.

При наличие на невалиден ред той трябва да бъде пропуснат, без да се прекратява обработката на файла.

### Задача 2

Да се разработи програма за обработка на резултати от куриерски доставки.

Входният файл съдържа по един запис за доставка на ред във формат:

```
id;courier;city;weight;price;status
```

Статусът може да бъде DELIVERED, FAILED или RETURNED.

Да се създаде подходящ клас за представяне на една доставка.

Програмата трябва да:

- зареди всички валидни записи от файла;
- групира доставките по куриер;
- изчисли общия приход от успешно доставените пратки;
- определи куриера с най-много успешно приключени доставки;
- изведе броя доставки за всеки град;
- определи градовете, в които има поне една неуспешна доставка;
- сортира успешно доставените пратки по цена в низходящ ред;
- запише обобщена статистика в изходен файл.

При наличие на невалидни числови стойности или непознат статус съответният запис трябва да бъде пропуснат, без да се прекратява работата на програмата.
