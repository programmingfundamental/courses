# Работен лист — Въведение в Софтуерното инженерство

Създайте собствен документ по следната структура:

1. Потребители и нужди.
2. Изисквания с идентификатор и критерий за приемане.
3. Ограничения и допускания.
4. Компоненти с вход, резултат и отговорност.
5. Проверки: изискване → вход → очакван резултат → действителен резултат.
6. Предаване на версия: файлове, инструкции, данни и отговорник.

При неизпълнена проверка запишете „не е изпълнена“. В това въведение не е необходима реализация на нов модел или инсталирана програмна среда.
