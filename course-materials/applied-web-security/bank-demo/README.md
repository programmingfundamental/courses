# БанкЛаб — учебна банка

Влезте с потребител `user` и парола `123456`, открийте сметка и проследете SQL инжекция, съхранен XSS и слабо шифроване на ЕГН. Приложението използва Java 17+, Spring Boot и H2 в паметта. Демонстрациите са предназначени за локално изпълнение с фиктивни данни.

## Стартиране

1. Разархивирайте целия пакет в нова папка. Проверете Java с `java -version`.
2. На Windows изпълнете `.\start.cmd`. На Linux/macOS изпълнете `sh start.sh`.
3. След `Started BankApplication` отворете `http://127.0.0.1:8087/login`.
4. Влезте с `user` / `123456`. Показват се три ваши сметки. В учебната банка първоначално има общо шест сметки.
5. Спрете с `Ctrl+C`. След рестарт се възстановяват шестте начални записа.

Пакетът съдържа готов `app/bank-demo.jar`. Стартирането му изисква само Java. За промени по кода използвайте JDK 17+, изпълнете `.\mvnw.cmd package` и стартирайте `java -jar target/bank-demo.jar`. При първо изграждане Maven Wrapper може да изтегли зависимости. На Linux/macOS командата за изграждане е `sh mvnw package`.

Има и учебен профил `admin` / `admin`, към който са отнесени останалите три начални сметки. Всички нови сметки получават за собственик текущия влязъл потребител. Данните от предишно стартиране се нулират, защото базата е в паметта.

## Теория

**SQL инжекцията** във филтъра възниква, защото въведеният вид сметка се добавя към текста на SQL заявката. Апострофът може да прекрати текстовата стойност и да позволи допълнително логическо условие. Първоначалното ограничение по собственик се заобикаля чрез `OR`.

**Съхраненият XSS** възниква при показване на записаното основание с `th:utext`. Браузърът получава активен HTML и изпълнява вмъкнатия JavaScript при отваряне на списъка. Политиката CSP в този учебен проект разрешава inline скриптове за демонстрацията.

**ROT5** е шифър с постоянно отместване на цифрите. Всяка цифра се заменя с `(цифра + 5) % 10`. Повторното прилагане възстановява оригинала. Форматът е `ROT5:`, последван от десет цифри. Алгоритъмът се разпознава по добавения префикс. Постоянното преобразуване разкрива и кои ЕГН са еднакви.

## Решен пример

### Извличане на всички сметки чрез филтъра

1. Влезте като `user`. Страницата **Изведи сметките ми** показва три записа.
2. В **Вид сметка** въведете `Спестовна` и натиснете **Изведи сметките ми**. Получавате една ваша сметка.
3. Заменете съдържанието на полето със следния текст и натиснете същия бутон.

```text
' OR '1'='1
```

Получавате шест записа, включително сметките на Мария Георгиева Стоянова и Николай Иванов Колев. При добавени сметки броят ще е по-голям. Полученото условие е следното, като `?` е параметърът за текущия потребител.

```sql
WHERE owner_login = ? AND account_type = '' OR '1'='1'
```

Винаги вярното условие след `OR` допуска всички записи. Натиснете **Изчисти**, за да видите отново собствените сметки.

### Изпълнение на съхранен XSS

Отворете **Откриване на сметка** и попълнете фиктивните данни.

| Поле | Примерна стойност |
| --- | --- |
| Собствено име | Елена |
| Бащино име | Петрова |
| Фамилия | Учебна |
| ЕГН | 0000001004 |
| Вид сметка | Спестовна |
| Дата на откриване | 2026-11-24 |

В **Основание за откриване** поставете следния учебен скрипт.

```html
<script>document.querySelector('h1').textContent='XSS DEMO';</script>
```

Натиснете **Открий сметката**. Сървърът генерира IBAN и отваря списъка. Заглавието се променя на **XSS DEMO** от записания скрипт. Презаредете страницата и проверете повторното изпълнение. Филтърът `Депозитна` изключва новата спестовна сметка, което връща обичайното заглавие. **Изчисти** отново включва записа и изпълнява скрипта.

### Разчитане на ЕГН

В списъка новото ЕГН е `ROT5:5555556559`. Премахнете префикса и завъртете всяка цифра с пет позиции. Получавате `0000001004`.

Същото преобразуване е реализирано в `ShiftCipher`.

```java
String egn = ShiftCipher.decrypt("ROT5:5555556559");
// egn е "0000001004"
```

IBAN се генерира от сървъра с учебен банков код `DEMO`, уникална последователност и контролни цифри. В списъка той е видим изцяло. ЕГН се съхранява в базата само в посоченото слабо шифровано представяне.
