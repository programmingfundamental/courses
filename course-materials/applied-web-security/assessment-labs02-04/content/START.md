# Практическо контролно по уеб сигурност

Разархивирайте целия пакет в отделна директория. Нужна е Java 17 или по-нова. За този готов пакет не са нужни Maven, Docker или интернет.

В Windows стартирайте `start.cmd`. В Linux/macOS изпълнете `sh start.sh`. Може и директно от директорията на пакета:

```text
java -jar web-security-assessment.jar
```

Отворете http://127.0.0.1:9010 в браузъра. Ако портът е зает, добавете `--server.port=9011` към Java командата и използвайте новия порт. Спрете приложението с Ctrl+C.

Прочетете страницата **Подготовка**, изпълнете петте проверки в **Лаборатория** и попълнете отговорите си. Учебните профили, пароли, данни и примерната проверка са в приложението.

В **Протокол** попълнете име или факултетен номер и натиснете **Подготви протокола**, после **Изтегли готовия JSON файл**. Предайте получения JSON файл по указания начин. Сайтът не го изпраща автоматично на преподавателя. Не записвайте пароли, cookies или tokens в свободния текст.

H2 запазва данните в папката `data`. Продължавайте от същата директория и със същия браузърен профил. Не изтривайте cookies преди предаването. За връщане на текущата проверка използвайте **Начални данни**; отговорите и дневникът се запазват.
