# XOR преобразуване на текст

XOR сравнява битовете на две числа: резултатният бит е 1, когато битовете се различават, иначе е 0. Например 5 (0101) XOR 3 (0011) = 6 (0110). В Java операторът е ^. Важното свойство е (A XOR K) XOR K = A: прилагането на същия ключ втори път връща началната стойност. Някои получени символи може да са непечатаеми, затова примерът показва числови кодове. Това е учебна трансформация, не реална защита.

Не ги използвайте за защита на чувствителна информация. Целта е да се упражнят алгоритми, преобразуване на текст, ключове, обратими операции, криптиране, декриптиране и елементарен криптоанализ; не се разглеждат съвременни криптографски системи.

## Приложение
Напишете конзолна програма, която прочита текст и цяло число, създава масив от XOR стойности, показва ги като числа и прилага XOR със същия ключ, за да възстанови текста.

## Насоки за реализация
- Изразът за всеки символ е text.charAt(i) ^ key.
- Използвайте int[] със същата дължина като текста.
- За показване на символ преобразувайте стойността с (char).

## Алгоритъм
1. За всеки символ прочети числовата му стойност.
2. Изчисли стойност XOR key и запиши числото в масив.
3. Изведи всички резултатни числа.
4. Приложи XOR със същия ключ към всяка стойност и преобразувай обратно към char.

Псевдокод:

```text
за всеки символ c:
    encoded[i] = c XOR key
за всяка стойност value в encoded:
    original = value XOR key
    добави (char) original към възстановения текст
```

## Примерен вход и изход
```text
Пример за операцията:
5 XOR 3 = 6

Вход за програмата:
Текст: A
Ключ: 7

Очакван резултат:
XOR стойности: 70
Повторен XOR възстановява: A
```
