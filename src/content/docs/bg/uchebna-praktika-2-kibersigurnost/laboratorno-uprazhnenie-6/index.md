# Лабораторно упражнение №6

## Тема
Честотен анализ на символи

## Продължителност

## Връзка с предходното упражнение
В упражнение 3 използвахме броячи за различни категории, а в упражнение 4 нормализирахме текст. Тук обобщаваме броенето в масив с по един брояч за всяка английска буква.

## Цел на упражнението
- Създайте масив int[26] за честотите на A-Z.
- Изчислете индекс на буква чрез c - 'A'.
- Изведете пълна таблица от A до Z, включително нулевите стойности.

## Необходими предварителни знания
Масиви, for, ASCII символи, броячи, String и преобразуване на малки букви в главни.

Условията на практическата, самостоятелната и допълнителната задача са на [страницата Задачи](/courses/bg/uchebna-praktika-2-kibersigurnost/laboratorno-uprazhnenie-6/zadachi/).

## Теоретична част
Масивът frequency има 26 позиции: 0 съответства на A, 1 на B и така до 25 за Z. След нормализиране на малка буква проверяваме дали символът е A-Z и увеличаваме frequency[c - 'A']. Така една структура съхранява броя за всички букви.

## Алгоритъм
1. Създай int[] frequency = new int[26].
2. Обходи всеки символ и превърни a-z в A-Z.
3. Ако символът е A-Z, увеличи честотата на индекс c - 'A'.
4. Обходи масива и изведи буквата и броя ѝ.

Псевдокод:

```text
frequency = масив от 26 нули
за всеки символ c:
    ако c е малка буква: преобразувай в главна
    ако c е между A и Z: frequency[c - 'A']++
за i от 0 до 25:
    покажи ('A' + i) и frequency[i]
```

## Демонстрационен пример

```text
Вход:
BANANA

Изход (ненулевите редове):
A -> 3
B -> 1
N -> 2

Таблицата на програмата съдържа и C -> 0 до Z -> 0.
```

## Пълно примерно решение

Работещият пълен пример е даден по-долу и се намира отделно във файла `06-frequency-analysis/src/Main.java`.


```java
import java.util.Scanner;

public class Main {
    public static int[] frequencyAnalysis(String text) {
        int[] frequency = new int[26];

        for (int i = 0; i < text.length(); i++) {
            char c = text.charAt(i);
            if (c >= 'a' && c <= 'z') {
                c = (char) (c - 'a' + 'A');
            }
            if (c >= 'A' && c <= 'Z') {
                frequency[c - 'A']++;
            }
        }
        return frequency;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Въведете текст: ");
        String text = scanner.nextLine();
        int[] frequency = frequencyAnalysis(text);

        for (int i = 0; i < frequency.length; i++) {
            char letter = (char) ('A' + i);
            System.out.println(letter + " -> " + frequency[i]);
        }
    }
}
```
