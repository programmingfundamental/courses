# Synthetic requests v1

400 синтетични записа, seed=42, CC0-1.0. Няма лични данни. Label 1 означава учебна ескалация; няма реални operational/ethical claims. Cohort A/B служи само за демонстрация на slice metrics и не е модел на защитена група.

CSV и manifest се версионират заедно в Git. SHA-256 идентифицира точните bytes; не е цифров подпис. За промяна създайте нов dataset version и manifest, не пренаписвайте v1. За големи данни преминете към DVC/object store; тук Git+manifest е еквивалентният малък data-versioning workflow.
