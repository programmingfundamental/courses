# Софтуерно инженерство за AI системи

Курсът разглежда проектирането, разработването, тестването и поддръжката на софтуерни системи с AI компоненти. В упражненията ще надграждате Task Manager с предложения за категории на задачи, като използвате UML модели, автоматизирани тестове и управление на версии на моделите.
