## Самостоятелни задачи


### Задача 1 — Точно търсене

Добавете GET /tasks/lookup?summary= с exact match и същата policy. Параметърът е задължителен, до 255 символа, без NUL; празен текст връща празен списък. Тествайте нормално summary, апостроф, кирилица, еднакви заглавия при alice/bob, SQL-подобен вход, %, _, празно и прекалено дълго поле. Anonymous няма достъп.

### Задача 2 — Контролирано сортиране

Разширете search с sort=summary или sort=deadline, по подразбиране summary. Непозната стойност → 400. Подреждането не променя изолацията между собствениците. Покажете положителен и отрицателен тест с PostgreSQL.
