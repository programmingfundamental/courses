# Уеб сигурност (Приложна)

В упражнения 1–10 ще надграждате защитата на Task Manager и ще я проверявате ръчно, като от упражнение 2 ще изпращате API заявки с Postman. В упражнение 11 ще автоматизирате регресионните проверки с JUnit и MockMvc. В [Помощни материали](/courses/bg/applied-web-security/resources/) ще намерите „БанкЛаб“ за демонстрации на SQL инжекция, съхранен XSS и слабо шифроване.
