## Task 1

Display the corresponding character from the repeating key below each character of HELLOWORLD.

## Task 2

Allow the user to select encrypt or decrypt mode through a console menu.

## Task 3

Encrypt `ATTACKATDAWN` using the key `LEMON` and verify the result `LXFOPVEFRNHR`.

## Task 4

Decrypt `LXFOPVEFRNHR` using the key `LEMON`.

## Task 5

Display the aligned repetition of the key for text that is longer than the key.

## Task 6

Check what encrypt and decrypt return when the key contains no English letters and display an appropriate message.

## Task 7

Modify encryption and decryption to accept lowercase letters and return uppercase letters.

## Task 8

Verify that decrypting the result of encryption restores the text.

## Task 9

Display the numerical values A=0, ..., Z=25 for the text and the repeating key.

## Task 10

Encrypt text while preserving spaces and punctuation; the position in the key should advance only when an English letter is processed.
