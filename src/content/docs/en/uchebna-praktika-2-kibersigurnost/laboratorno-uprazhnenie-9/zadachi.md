## Task 1

Calculate 9 XOR 5 manually in binary and decimal form and verify the result in the program.

## Task 2

Restrict the key to a small non-negative number and try different texts.

## Task 3

Apply XOR twice with key 7 to the characters `A` and `B` and verify that they are restored.

## Task 4

Display the XOR results for the characters as binary values with leading zeros up to 8 bits.

## Task 5

Test key 0 and explain the result.

## Task 6

Handle empty text by displaying an empty list of values.

## Task 7

Verify that each XOR result can be restored by applying the same key again.

## Task 8

Display the numerical results for each character without converting them back to text.

## Task 9

Compare the results for the same text using keys 1, 7, and 31.

## Task 10

Read a sequence of numerical XOR values separated by spaces and restore the original text using the entered key.
