## Task 1

Test text whose length is not divisible by the number of columns. Display the X characters added to the ciphertext and verify that they do not remain in the restored result.

## Task 2

Add a visual representation of the matrix before and after transposition.

## Task 3

Test the transposition with one column and confirm that the text is restored.

## Task 4

Use text whose length is exactly divisible by the number of columns and confirm that no padding character is required.

## Task 5

Test text that is shorter than the number of columns and display the added X characters.

## Task 6

Add a check for an invalid number of columns and display a message instead of creating a matrix.

## Task 7

Display the row/column coordinates of each character while filling the matrix.

## Task 8

Verify reversibility for several text lengths and numbers of columns.

## Task 9

Compare the results using 2, 3, and 4 columns for the same text.

## Task 10

For each character in the text, display its original coordinates in the matrix and its position in the ciphertext.
