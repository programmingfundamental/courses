## Task 1

Display how many characters were removed: the length of the input minus the length of the result.

## Task 2

Support Cyrillic letters as well by converting them separately and explicitly explaining the new character ranges.

## Task 3

Convert the normalized text to lowercase instead of uppercase.

## Task 4

Modify the normalization so that digits are preserved as well.

## Task 5

Count how many uppercase and lowercase English letters are present in the input.

## Task 6

Replace each sequence of consecutive spaces with exactly one space, with no leading or trailing spaces.

## Task 7

Check whether two texts are equal after normalization.

## Task 8

Display separately the number of letters, digits, and removed characters.

## Task 9

Remove consecutive duplicate characters, keeping the first character from each sequence.

## Task 10

Check whether the normalization is idempotent: normalizing the result again should leave it unchanged.
