## Task 1

Test keys 0, 26, and 29 and explain why 0 and 26 produce the same transformation.

## Task 2

Preserve lowercase letters and punctuation in their original positions.

## Task 3

Test negative and large keys and normalize the key to the range from 0 to 25.

## Task 4

Demonstrate with a program that decrypting the ciphertext with the original key restores the normalized text.

## Task 5

Display the result for the text ZOO using a key of 3.

## Task 6

Display all 25 non-zero decryption variants for the given text.

## Task 7

Add a check for empty input and display an empty result without an error.

## Task 8

Compare encryption with a key of 29 and a key of 3.

## Task 9

Display the normalized text and the ciphertext separately for input containing spaces and punctuation.

## Task 10

Encrypt and decrypt text while preserving lowercase letters, spaces, and punctuation; verify that the original input is restored.
