## Task 1

Add a check for a non-numeric key that displays a message and allows the user to continue using the menu.

## Task 2

Add a command that combines text analysis and normalization into a single sequence.

## Task 3

Add a command for counting the occurrences of a selected character.

## Task 4

Add a command for displaying all Caesar decryption variants.

## Task 5

Modify the menu to display a message for an invalid choice and then continue.

## Task 6

Check for an empty Vigenere key and do not perform encryption if the key is invalid.

## Task 7

Add a command for displaying the frequency table only for letters that occur in the text.

## Task 8

For the normalization command, also display the number of removed characters.

## Task 9

Add a command that reverses the text and checks whether it is a palindrome.

## Task 10

Add a command that normalizes the text, encrypts it using the Caesar cipher, and displays the letter frequencies in the ciphertext.
