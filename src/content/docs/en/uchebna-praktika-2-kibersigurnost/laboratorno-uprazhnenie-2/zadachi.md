## Task 1

Count all positions where a selected character occurs instead of returning only the first one.

## Task 2

Perform the same two searches using indexOf() and compare the results with those returned by your own methods.

## Task 3

Find the last occurrence of a selected character using your own method that iterates through the text from end to beginning.

## Task 4

Count the occurrences of a substring, allowing overlaps. For example, in `aaaa`, the substring `aa` occurs three times.

## Task 5

Find the position of a character regardless of letter case for English letters.

## Task 6

Display all starting positions where a selected substring occurs.

## Task 7

Display and explain the result when searching for an empty substring.

## Task 8

Compare searching for a single character with searching for a one-character string using `indexOf()`.

## Task 9

Find the first occurrence of a substring after a given starting position.

## Task 10

Find the last occurrence of a substring using your own method that searches from end to beginning.
