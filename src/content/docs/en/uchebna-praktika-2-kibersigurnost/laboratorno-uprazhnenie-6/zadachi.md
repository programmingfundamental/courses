## Task 1

Find and display the letter with the highest frequency. In case of a tie, you may choose the first one alphabetically.

## Task 2

Display the percentage of each letter relative to the total number of counted letters.

## Task 3

Display only the letters with a frequency greater than zero.

## Task 4

Count the occurrences of a selected letter, regardless of letter case.

## Task 5

Calculate the total number of counted letters and confirm that it is equal to the sum of all frequencies.

## Task 6

Find the least frequent letter that occurs in the text.

## Task 7

Display a simple text histogram using one asterisk for each occurrence.

## Task 8

Display the letters in descending order of frequency; in case of a tie, preserve alphabetical order.

## Task 9

Calculate the proportion of each letter relative to the total number of characters, rather than only to the number of letters.

## Task 10

Find the most frequent vowel in the text, regardless of letter case; display a message if there are no vowels.
