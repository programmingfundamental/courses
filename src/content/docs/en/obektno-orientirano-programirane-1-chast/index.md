This course introduces object-oriented programming with Java through classes, objects, encapsulation, inheritance, and polymorphism. You will work with exceptions, strings, generics, collections, and input and output operations.

- [Laboratory Exercise 3 — Encapsulation, access modifiers, inheritance, and relationships between classes](/courses/en/obektno-orientirano-programirane-1-chast/laboratorno-uprazhnenie-03/)
- [Laboratory Exercise 4 — Abstraction, abstract classes, and interfaces](/courses/en/obektno-orientirano-programirane-1-chast/laboratorno-uprazhnenie-04/)
- [Laboratory Exercise 5 — Static and dynamic polymorphism](/courses/en/obektno-orientirano-programirane-1-chast/laboratorno-uprazhnenie-05/)
- [Laboratory Exercise 6 — Exception handling](/courses/en/obektno-orientirano-programirane-1-chast/laboratorno-uprazhnenie-06/)
