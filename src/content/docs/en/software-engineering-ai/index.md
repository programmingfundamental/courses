This course covers the software lifecycle and Scrum teamwork for systems with AI components. As an AI engineer, you will extend Task Manager through requirements analysis, UML modeling, data preparation, model evaluation, deployment, and maintenance. The teaching materials are available in Bulgarian via the language selector.
