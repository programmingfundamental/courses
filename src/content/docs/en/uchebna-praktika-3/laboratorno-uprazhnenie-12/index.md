# Laboratory Exercise 12

## Adapting the Strategy During AI-Assisted Development

### Objective

The objective of this exercise is to independently continue the development of the application from Laboratory Exercise 11, adapting the strategy for working with the AI assistant according to the current state of the project, the tasks that arise, and the results obtained.

A user interface must be added to the developed backend, and automated tests must be implemented. For the individual tasks, the required context, the scope of the changes, and the method for verifying the resulting solutions are determined independently.

During the work, the AI_WORKLOG.md file created in Laboratory Exercise 11 should continue to be updated. Key decisions and significant changes in the strategy for working with AI should be documented.
